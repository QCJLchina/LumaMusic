# 液态玻璃 UI 改版与验证

验证日期：2026-09-07。前端使用项目自带 .NET 10.0.400、Windows App SDK 1.8、Win2D 1.4；保持 Windows 10 2004+、x64 的项目目标。

## 实现

- 音乐库默认专辑网格，歌曲与艺术家在页面内切换，保留搜索、收藏、播放列表和导入；专辑和艺术家详情提供返回浏览入口。
- `GlassSurface` 统一悬浮导航、播放条、队列的应用内 Acrylic、圆角、阴影与边缘高光；边缘透镜来自共享封面背景的 1.035 倍局部采样，限于 3 DIP 边缘，不扭曲文字或任意滚动内容。
- 播放页移除封面倒影，保留大封面、逐行歌词与输出状态；歌词透明度由 XAML 属性统一维护，避免主题切换／控件重建后当前行变淡。
- 宽度不足 1100 DIP 时折叠图标导航、收起音量滑块；浮动播放条保留进度和主操作。窗口最小客户布局按 760×560 DIP 的安全边界处理。
- 封面背景降低饱和度与模糊强度，缓存包含文件更新时间，异步渲染仅接受最新请求；背景流光使用 Composition Translation，隐藏、托盘、减少动态等状态停止装饰动画。
- 复用主题与动态设置，增加减少透明效果；省电、系统特效关闭、高对比度和低图形能力走材质降级路径。保留工作区已有的单击／双击播放偏好。
- 音频 API、原生源码和媒体库结构未改动；新增偏好缺失时采用默认值。

## 构建与测试

最终自包含开发包位于 `dist/LumaMusic-glass/`，入口为 `LumaMusic.exe`。已启动验证；正常发布 DLL 不包含 `RunUiRegression` 测试入口。发布构建通过，有一条原有更新链接异步调用的 CS4014 警告。

执行 `powershell scripts/test-ui.ps1 -Python <python.exe>` 可重跑原生 UI 集成回归。需要先准备项目依赖、原生组件与 Pillow。脚本生成专用 `build/ui-regression-时间戳` 档案；所有音频为数字静音，关闭联网，结束后自动退出。

最终结果：**61/61 通过**。原始记录：`build/ui-regression-20260907-155947/ui-regression.json`；脚本日志：`build/ui-evidence/ui-run.log`。

覆盖内容：

- 浅色、深色 × 1000×660、1320×860、1920×1080 窗口，检查音乐库、封面、歌词、队列和播放控件边界；实测 RasterizationScale 为 1。
- 专辑默认视图、艺术家聚合与返回、歌曲视图、搜索／无结果、收藏与播放列表筛选、空库和 1 万首曲目。
- 快速连续更换背景后清空封面、重新渲染背景、减少透明／动态、隐藏和恢复策略。
- 真正的 WAV 导入、收藏数据库读回、播放列表创建后导航更新、队列上移／移除、音量偏好更新。
- 原生静音播放、连续开关队列、进度跳转、暂停恢复、歌词生成、切主题后当前歌词不透明、外观及点击偏好持久化。

原生数据测试由本机 MinGW g++ 编译 `tests/native_tests.cpp` 并通过，覆盖 DoP 数据往返、24 位符号处理、拆块、1／2／6／8 声道和 DSD 静音。

`tests/audio_smoke.py` 通过：2／6 声道 DSD raw 与 PCM 解码、精确跳转、WASAPI 共享与独占真实静音输出。日志：`build/ui-evidence/audio-smoke.log`。UI 动画期间音频欠载计数为 0，未增加。

## 视觉与性能证据

`build/ui-evidence/` 包含：

- `before-dark.png`：官方旧版对照。
- `after-dark-library.png`、`after-light-library.png`：最终开发包的音乐库。
- `after-dark-now.png`、`after-light-now.png`：最终开发包的播放页。
- `page-transition.gif`：13 张实际窗口帧的页面切换记录，约 7 fps 的采集速度，仅用于展示过程，不代表应用帧率。

同机、同一生成封面与 36 首静音曲目的 5 秒空闲快照：旧版 CPU 时间 890.625 ms／工作集 266.8 MB；新版 CPU 时间 203.125 ms／工作集 274.0 MB。旧版显示歌曲列表、新版显示专辑网格，属于对应默认首页的单次对照，不能推广为所有场景的性能结论。

回归记录中的 `p95UiCallbackMs` 是 `CompositionTarget.Rendering` 回调间隔，**不是 GPU 呈现帧时间或 60 fps 达标证明**。最后一轮为 38.30 ms（211 个回调）；之前单窗口回归为 15.15 ms。采集与窗口状态不同，因此暂不判定稳定 60 fps 已达标。音频欠载和真实回放状态单独读回验证。
